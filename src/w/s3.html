自作Google Drive MCPサーバー セットアップ

既存のGoogle Drive連携には「既存ファイルの中身を更新する」機能が無いため、それを補うために作った自作MCPサーバー(gdrive-mcp)。files.updateでfileIdを保ったまま中身を差し替える。

ブラウザ操作が1回必要 スコープ: drive(全体への読み書き)
1

OAuthクライアントIDを作る(デスクトップアプリ)

Google Cloud Consoleで新しいOAuthクライアントIDを作成する。種類は「デスクトップアプリ」を選ぶ(s2で書いた「ウェブアプリケーション」とは別種類)。

2

credentials.json を配置する

ダウンロードしたJSONを、server.pyと同じフォルダに credentials.json という名前で置く。

3

依存関係をインストールする

pip install -r requirements.txt
4

初回のみブラウザで認可する

py server.py --auth-only

実行すると既定のブラウザが開き、Googleアカウントでのログインと権限の許可を求められる。成功すると token.json が生成され、以降は自動で使われる。

ここは利尻にはできない

ブラウザでの認可操作は、たかしさんのPC・ブラウザ・Googleアカウントで完結する必要がある。代行できない。

5

Claude Codeに登録する(次のステップ・未実施)

claude mcp add で登録する。ここまではまだ進めていない。

使えるツール(5個)

list_files
ファイルを検索・一覧する
get_file_metadata
名前・種類・更新日時などを取得する
read_file
中身をテキストとして読む
create_file
新規ファイルを作成する
update_file
既存ファイルの中身を差し替える — 今回作った本命の機能
スコープについての注記

drive.file(このアプリが作った/開いたファイルのみ)の方が権限は狭く安全だが、日次バックアップなど既存の別経路で作られたファイルも更新したいという要件のため、今回は広めのdriveスコープにしている。狭めることも可能。

コード本体: gdrive-mcp/(このrepoとは別、ローカルのみ)。まだClaude Codeへの登録は済んでいない。
